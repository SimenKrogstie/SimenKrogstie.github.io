UM

Urban Mobility and Building Indicators

Geospatial

Investigates how bike-sharing usage relates to land-use structure and building typology across Ullern and Grünerløkka in Oslo, combining Oslo Bysykkel trip data, OpenStreetMap building footprints (via OSMnx), and SSB population/district boundaries. Computes mobility and building indicators, compares daily usage profiles between districts, and presents the results through an interactive Folium map. Completed for the GMGI221 course at NMBU (autumn 2025).

Python OSMnx Folium Spatial Analysis

DynaMo

Deep Learning/Software

A neural network optimization framework built for NMBU's INF202 course that uses dynamic low-rank techniques to cut the memory and compute cost of training, reducing environmental impact. Models are defined through modular TOML configs supporting both dense and low-rank layers, with a dedicated DynamicLowRankOptimizer, a GUI for training and MNIST prediction, and a CLI-driven workflow.

Python Neural Networks Low-Rank Optimization TOML

WeatherSentiment

Data Science/NLP

Explores correlations between weather patterns and public sentiment across Europe by combining weather datasets with transformer-based sentiment scoring of social media text. Aggregates emotional tone by country over time, joins it with geographic boundary data, and produces interactive web maps with temporal controls alongside static analysis in a Jupyter notebook.
